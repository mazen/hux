# Each extension point uses the mechanism that matches its trust level

There is no single plugin system. Third-party tools are WebAssembly components run by the Gateway with capabilities granted explicitly, never raw sockets or raw secrets. Outside tool servers are reached over MCP and treated as untrusted. Skills are instruction-only documents. Channels, renderers and hardware-bound Drivers run as separate processes that speak the Node protocol. Model providers and storage are native Rust interfaces compiled in. Policy, secrets, egress and audit are core and never pluggable. We rejected loading native dynamic libraries (no stable Rust ABI, full process privileges) and the in-process plugin model of OpenClaw and Hermes, whose plugin registries have shipped credential stealers.
